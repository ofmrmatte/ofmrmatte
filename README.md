# Matheus Ferreira Folgado Portfolio

Aplicação Next.js do portfólio profissional de Matheus Ferreira Folgado.

## Scripts

```bash
npm install
npm run lint
npm run typecheck
npm run build
npm run dev
```

## Imagens

As imagens finais devem ser publicadas no Supabase Storage e configuradas por:

```bash
NEXT_PUBLIC_HERO_IMAGE_URL=
NEXT_PUBLIC_PORTRAIT_IMAGE_URL=
NEXT_PUBLIC_SUPABASE_IMAGE_HOST=
```

Bucket alvo: `portfolio-assets`.
